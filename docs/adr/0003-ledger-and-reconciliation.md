# ADR-0003: 수동 송금과 현금 원장 대사

상태: proposed
작성일: 2026-10-23
결정자: 미지정 — 프로젝트 책임자/기술 리드 채택 필요

## 맥락
은행 API 자격과 파일 서식이 미확정이며 수동 송금과 은행 거래가 동시에 나타날 수 있다.

## 결정 또는 제안
검증된 거래 파일을 먼저 지원한다. payment_record는 송금 보고이며 은행 거래 확정 시 현금 원장을 한 번 만든다. 대사는 연결만 수행한다. 원장 정정은 반대/대체 entry다.

## 대안
송금 보고 때마다 출금을 만들고 은행 입수 때 또 만드는 방식은 이중 집계 위험. ID 없는 해시 중복 자동 제거는 정상 거래 소실 위험.

## 결과·제약
은행 API 없이도 동작하지만 파일 출처·기간·기준시각을 공개한다. 현금 원장 모델이며 복식부기/세무 요건을 인증하지 않는다.
