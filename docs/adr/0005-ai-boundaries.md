# ADR-0005: AI 검색의 권한과 근거

상태: proposed
작성일: 2026-10-23
결정자: 미지정 — 프로젝트 책임자/기술 리드 채택 필요

## 맥락
정형 조회와 RAG 분리는 사용자 확정. 구체적 도구/공급자는 미정이다.

## 결정 또는 제안
정형은 typed query catalog와 파라미터화 SQL, 비정형은 ACL 선필터와 버전/위치 인용으로 구성한다. 변경 도구를 제공하지 않는다.

## 대안
임의 text-to-SQL 실행과 금액의 RAG 추정은 채택하지 않는다. 검색 후에만 ACL을 거는 방식은 누출 위험.

## 결과·제약
외부 LLM 전송 조건/모델/임베딩/벡터 저장소 채택은 별도 검증. 동일 조회를 AI 없이도 제공한다.
