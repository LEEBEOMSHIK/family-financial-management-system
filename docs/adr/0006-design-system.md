# ADR-0006: 토큰 기반 UI

상태: proposed
작성일: 2026-10-23
결정자: 미지정 — 프로젝트 책임자/기술 리드 채택 필요

## 맥락
금융 관리 화면은 금액·상태·근거를 일관되게 표현해야 한다.

## 결정 또는 제안
의미 CSS 변수, 시스템 한국어 폰트, 브랜드 핑크 #FF849E / 블루 #6492DB와 가독성용 진한 파생색, 명시적 상태 텍스트, 44px 조작 목표, WCAG 2.2 AA 지향을 제안한다.

## 대안
은행 브랜드 모사와 색상만의 상태는 배제한다. UI 프레임워크를 미리 강제하지 않는다.

## 결과·제약
JSON/CSS 동기화, 접근성 검증이 필요하다. Tailwind/shadcn/Radix/폰트는 검증 후 선택하며 현재 의존성으로 주장하지 않는다.
