# ADR-0004: 공식 알림 채널과 재시도

상태: proposed
작성일: 2026-10-23
결정자: 미지정 — 프로젝트 책임자/기술 리드 채택 필요

## 맥락
세 날짜/현직 총무는 확정이고 발송 시각·제공자·공석 처리 등은 미정이다.

## 결정 또는 제안
KST 09:00과 당일 유효성, durable outbox, 발송 직전 역할 재검증, 결과 불명 unknown을 제안한다. 알림톡 공식 조건을 먼저 확인한다.

## 대안
서버 메모리 타이머는 유실 위험. 친구 API/나에게 보내기는 임의 자동 대체로 채택하지 않는다. 외부 exactly-once를 보장하지 않는다.

## 결과·제약
공식 이용 자격/템플릿/수신 검증 전에는 sink만 사용한다. 웹 알림함은 대안 제안이며 카카오 요건 완료가 아니다.
