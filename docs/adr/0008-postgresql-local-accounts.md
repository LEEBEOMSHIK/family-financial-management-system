# ADR-0008: PostgreSQL과 개별 로컬 계정

상태: accepted-for-local-development / 2026-10-24

사용자가 실제 DB 구성과 가족별 계정·권한 관리를 요청했다. ADR-0007의 개발 역할 버튼과 메모리 세션, JSON 역할 저장을 현재 실행 경로에서 대체한다.

PostgreSQL 18.6과 psycopg 3.3.6을 채택한다. owner/runtime 및 개발/테스트 DB를 분리하고 SQL 마이그레이션 체크섬과 append-only 이력을 적용한다. 기존 서버를 변경하지 않는 별도 로컬 클러스터를 사용한다. Docker는 추가하지 않는다.

최초 관리자만 로컬 초기화로 만든다. 가족은 관리자 초대로 가입하며 기본 일반사용자다. 총괄관리자만 역할을 바꾸며 요청 시점의 DB 권한을 검증한다. scrypt 비밀번호 및 DB의 해시 세션/초대 토큰을 사용한다. 초대한 관리자의 현재 권한도 재검증한다.

현재 인증은 로컬 개발 범위다. 외부 배포와 계정 복구를 완성한 것으로 간주하지 않는다. 거래 데이터는 여전히 합성 자료다. 구현·실행·복구는 [운영 안내](../engineering/postgres-local.md), 요구사항과 소유권은 [작업 계획](../plans/postgres-accounts.md)에 기록한다.
