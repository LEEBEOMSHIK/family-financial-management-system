# ADR-0009: 개인 기본 계좌와 비공개 이미지 증빙

상태: accepted-for-local-development / 2026-10-24

사용자가 개인별 기본 계좌 지정과 사용 후 정산/사용 전 선지급 구분을 확정했다. 정산은 영수증 필수이며 선지급은 사유를 기록하고 사후 영수증을 제출한다. 승인 인원 정책을 확정한 것으로 해석하지 않는다.

개인 계좌와 기본값 이력을 PostgreSQL에 보존한다. 계좌는 덮어쓰지 않고 새로 등록하며 요청은 제출 당시 계좌 ID에 연결한다. 번호는 cryptography Fernet으로 암호화하고 DB 밖의 전용 키로 관리한다. 기본 API는 마스킹 정보를 반환하고 명시적인 전체 번호 열람은 서버 권한 확인과 감사 기록을 거친다.

이미지는 원본과 메타데이터 제거 PNG 미리보기를 각각 암호화해 PostgreSQL bytea로 저장한다. 소규모 로컬 서비스에서 DB·파일 분리로 생기는 유실/정합성 문제를 줄이는 선택이다. 대규모 운영에서는 같은 저장 인터페이스를 비공개 객체 저장소로 전환할 수 있다. 파일당/요청당 크기 제한을 둔다.

Pillow로 허용 형식과 크기를 검증하고 재인코딩한 미리보기만 제공한다. 이 검증은 외부 백신 검사 완료를 뜻하지 않는다. 공개 운영 전 악성코드 검사·업로드 처리량·보관 정책을 검증해야 한다. 계좌/증빙 원본은 로그·Git·LLM에 보내지 않는다.

의존성: cryptography 50.0.2, Pillow 13.0.0. 버전·라이선스·공식 근거는 API dependency-metadata.json에 고정한다. 실행 및 복구는 [계좌·증빙 운영 안내](../engineering/accounts-evidence.md), 변경·검증은 [구현 기록](../plans/accounts-evidence.md)을 따른다.
