# ADR-0001: 사용자 확정 제약

상태: accepted-from-request
작성일: 2026-10-23
결정자: 사용자 요청에 명시된 범위

## 맥락
2026-10-23의 사용자 요청과 조회 가능한 참조 대화가 근거다. 운영규정 원문은 미확보다.

## 결정 또는 제안
Next.js+TypeScript, Python, Docker 없는 로컬, 운영만 Docker, 최초 카카오뱅크와 은행 확장, 총무 수동 송금, D-1/D0/미처리 D+1 현직 총무 알림, 공식 조건 검토 후 카카오톡 우선, 정형 검색/RAG 분리, RBAC/증빙 이력을 유지한다.

## 대안
자동 송금, 로컬 Docker 강제, 무조건 사용 가능한 은행/카카오 API 가정은 채택하지 않는다.

## 결과·제약
확정되지 않은 승인권자·회비액·임기·정족수·라이브러리는 이 결정에 포함되지 않는다.
