## 미확정 사항과 차단 범위

추가 요구사항 R20 — 관리자 파일 관리 / CONFIRMED: 모임 운영정책·규정 등 공용 문서를 관리할 수 있어야 한다. 세부 설계와 인수 기준은 [파일 관리](../design/file-management.md)에 기록한다. 현재 앱에 구현된 기능은 아니다.

| 결정 ID | 확인할 내용 | 확인 책임 제안 | 미확정일 때 |
| --- | --- | --- | --- |
| U01 | 규정 원문·현행 개정본 | 프로젝트 책임자/총무 | 실제 회비 부과·승인·투표 차단, 합성 자료 설계 진행 |
| U02 | 은행 API 이용 자격/계약/명의/동의 | 책임자+연동 담당 | 은행 API 비활성, 실제 서식 확인 후 파일 방식 |

## 범위 밖

은행 앱 조작/스크래핑, 은행 로그인 정보 저장, 자동 송금, 투자/세무 자문, 회계 기준 준수 인증, 공개 다중 고객 서비스, AI의 자율 승인·투표·권한 부여는 현재 범위가 아니다.
