## 시작 순서

1. 이 폴더를 프로젝트 작업 폴더로 연다.
2. 루트 AGENTS.md, PROJECT_GUIDELINES.md 및 docs/plans/implementation-plan.md를 읽는다.
3. 저장소 루트에서 `python scripts/validate_foundation.py`를 실행한다. Python 3.11 이상이 필요하다.
4. P0에서 운영규정 원문과 정책을 매핑하고 의존성 후보를 검증한다.
5. P1부터 실제 앱 골격을 구현한다. 현재는 문서·설정·UI 예제이며 실행 가능한 전체 웹앱은 아니다.

## 저장소 관리

기존 원격 파일은 없어 덮어쓰지 않았다. 문서 배포 묶음의 MANIFEST.sha256은 수정 가능한 작업 저장소에 옮기지 않았다. 실제 운영규정·계좌·증빙·비밀은 Git에 포함하지 않는다.

초기 커밋과 원격 반영을 수행하면 위 변경 상태도 갱신한다. 앱 의존성 설치, 실계정 연결, 외부 발송, 배포는 현재 준비 범위에 포함되지 않는다.

## 로컬 점검

초안 79개 파일을 해시 대조 후 복사하고 이 준비 기록을 추가했다. 작업 저장소의 검증 스크립트는 `.git`, 의존성/빌드 폴더 및 비공개 데이터 폴더를 순회하지 않도록 조정했다. 문서 묶음 검증과 제품 테스트를 구분하는 원칙은 유지한다.
